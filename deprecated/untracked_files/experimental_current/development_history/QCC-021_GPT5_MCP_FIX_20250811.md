## 🔧 GPT-5 MCP温度パラメータエラー修正

### 問題の特定
**エラー**: `400 Unsupported value: 'temperature' does not support 0.7 with this model. Only the default (1) value is supported.`

**原因**: OpenAI GPT-5モデルは温度パラメータに制限がある（デフォルト値1のみサポート）

### 解決策実装
**修正ファイル**: `/home/shakufuku/.claude/mcp-servers/openai/server.js`

**修正箇所**: 132-138行目
```javascript
// GPT-5系モデルでは温度パラメータを1に固定（OpenAI制限回避）
if (model.startsWith('gpt-5')) {
  console.error(`[MCP] GPT-5モデル検出: temperature=1固定（要求値=${temperature}は無視）`);
  completionParams.temperature = 1;
} else {
  completionParams.temperature = temperature;
}
```

### 修正内容
1. **GPT-5モデル検出**: `model.startsWith('gpt-5')`で識別
2. **温度値強制設定**: GPT-5の場合はtemperature=1に固定
3. **ログ出力**: 要求値と実際送信値をログ表示
4. **他モデル互換性**: GPT-4等では従来通り動作
