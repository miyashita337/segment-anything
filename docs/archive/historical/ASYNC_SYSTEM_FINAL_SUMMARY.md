### 🔍 判明した限界

1. **GPU処理の本質的制約**
   ```
   SAM推論時間: 180-540秒/枚（3-9分）
   - GPU処理中は割り込み不可
   - 非同期化してもGPU処理時間は変わらない
   - メモリ使用量: 1.3-3.2GB/プロセス
   ```

2. **非同期処理の適用限界**
   - I/O待機がほぼない（GPU処理がボトルネック）
   - プロセス終了シグナルの伝播問題
   - 複雑性増加に対して効果限定的

## 💡 得られた知見

### 1. **非同期化の適用条件**
```
効果的な場合:
- I/O集約的処理（ファイル、ネットワーク）
- 多数の軽量タスク
- 待機時間の有効活用

効果限定的な場合:
- GPU/CPU集約的処理 ← SAMはこれ
- 単一重量タスク
- リソース競合がある場合
```

### 2. **SAM処理の実態**
- 1枚3-9分は「正常」な処理時間
- バッチサイズ増加で線形に時間増加
- GPU並列化の限界（メモリ制約）

### 3. **実用的アプローチ**
- 小バッチ（1-2枚）での確実処理
- 十分なタイムアウト（10分+/枚）
- 外部プロセス管理ツールの活用
