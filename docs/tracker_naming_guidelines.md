## 🎯 基本原則

### 1. 新規格適用対象
- ✅ **2025-08-17以降の新規トラッカー**: 必須適用
- ⚠️ **既存トラッカー**: 現状維持（段階的移行検討）
- 🔒 **完了済みトラッカー**: 保護対象（変更禁止）

### 2. 命名フォーマット
```
[機能コード]-[連番]

例: QUAL-001, EXTR-002, INTG-003
```

### 3. 機能コード（必須暗記）

| コード | 機能領域 | 用途例 |
|--------|----------|--------|
| **QUAL** | 品質管理 | 品質評価・改善・監視システム |
| **EXTR** | 抽出処理 | SAM/YOLO抽出・分割・前後処理 |
| **INTG** | 統合処理 | CI/CD・システム統合・パイプライン |
| **TEST** | テスト作業 | 単体・統合・性能テスト |
| **DOCS** | ドキュメント | 文書作成・更新・整備 |
| **PHSE** | Phase作業 | フェーズ別開発・マイルストーン |
| **OPTM** | 最適化 | パフォーマンス・メモリ・速度改善 |
| **MAINT** | メンテナンス | 保守・クリーンアップ・リファクタ |

## 📋 実践ガイド

### ステップ1: 機能分析
新しいタスクを開始する前に、以下の質問で機能領域を特定：

```
Q1: このタスクの主目的は？
- 品質向上 → QUAL
- データ抽出 → EXTR  
- システム統合 → INTG
- テスト・検証 → TEST
- 文書作成 → DOCS
- フェーズ作業 → PHSE
- 性能改善 → OPTM
- 保守作業 → MAINT

Q2: 複数に該当する場合は？
→ 最も時間を費やす領域を主機能として選択
```

### ステップ2: 連番確認
```bash
# Google Sheetsで該当機能コードの最新番号を確認
python tools/progress_tracker/cli.py list | grep "QUAL-"

# 出力例:
# QUAL-001: 品質評価システム改善
# QUAL-002: 統計分析精度向上
# → 次は QUAL-003
```

### ステップ3: トラッカー作成
```bash
# 新規トラッカー作成
python tools/progress_tracker/cli.py create QUAL-003 --description "新品質評価アルゴリズム実装"

# ワークスペース作成
mkdir -p /mnt/c/AItools/lora/train/yado/tracker-workspace/QUAL-003/
```

## 💡 分類の判断例

### 典型的な例

#### ✅ 正しい分類
- **QUAL-001**: "キャラクター抽出品質向上" → 品質管理
- **EXTR-001**: "SAM+YOLO統合抽出パイプライン" → 抽出処理
- **INTG-001**: "GitHub Actions CI/CD設定" → 統合処理
- **TEST-001**: "抽出精度テスト自動化" → テスト作業
- **DOCS-001**: "API仕様書作成" → ドキュメント
- **PHSE-001**: "Phase 2マイルストーン達成" → Phase作業
- **OPTM-001**: "GPU メモリ使用量最適化" → 最適化
- **MAINT-001**: "非使用コード削除" → メンテナンス

#### ❌ 分類迷いやすいケース
| タスク内容 | 迷いやすい選択 | ✅ 正解 | 理由 |
|------------|----------------|---------|------|
| 抽出結果の品質テスト | TEST vs QUAL | **QUAL** | 品質向上が主目的 |
| テスト用ダッシュボード作成 | TEST vs DOCS | **TEST** | テストが主目的 |
| 統合テスト実行 | INTG vs TEST | **TEST** | テストが主目的 |
| パフォーマンステスト | OPTM vs TEST | **OPTM** | 最適化が主目的 |

## ⚠️ 注意事項

### 絶対に避けるべき命名
- ❌ **個人名**: `TANAKA-001`, `SATO-002`
- ❌ **日付ベース**: `20250817-001`, `AUG17-001`  
- ❌ **プロジェクト名**: `SEGMENT-001`, `SAM-001`
- ❌ **技術名**: `PYTORCH-001`, `CUDA-001`
- ❌ **抽象名**: `MISC-001`, `OTHER-001`, `GENERAL-001`

### 命名時の確認事項
1. **機能コード**: 8つの定義済みコードから選択済み？
2. **連番**: 同一機能コード内で重複していない？
3. **説明**: トラッカー目的が明確に記述されている？
4. **適用時期**: 2025-08-17以降の新規作成？
